# Judge for Android

Kotlin + Jetpack Compose. Package `com.okjudge.judge` (debug builds add
`.debug`).

## Sign-in

Every verdict needs an account: "Get the verdict" opens sign-in when signed
out and goes on to the verdict afterwards. Methods follow `GET /api/v1/config`
(`signIn.google`, `signIn.emailCode`); Apple is iOS only and never shown here.

- Google: Credential Manager ("Sign in with Google") returns an ID token for
  the web client id (`GOOGLE_SERVER_CLIENT_ID`), traded at
  `POST /api/auth/sign-in/social`.
- Email: a six-digit code (`/api/auth/email-otp/send-verification-otp`, then
  `/api/auth/sign-in/email-otp`).
- The session token is sent as `Authorization: Bearer` and stored AES-GCM
  encrypted with an Android Keystore key (`core/auth/KeystoreTokenStore.kt`).
  A 401 `signin_required`, or `/api/v1/me` answering without a user, ends the
  session. Sign-out and account deletion never touch the history on the phone.

## Build

Needs the Android SDK (`local.properties` with `sdk.dir`, not committed) and a
JDK. Android Studio's bundled JBR (JDK 25) works:

```sh
# Git Bash; in PowerShell set $env:JAVA_HOME instead
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
./gradlew assembleDebug testDebugUnitTest
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Toolchain: Gradle 9.8.2, AGP 9.4.1 (built-in Kotlin), Kotlin 2.4.21, KSP
2.3.12, compileSdk 37, targetSdk 36, minSdk 26, Java 17 bytecode.

## Configuration (`gradle.properties` or `-P`)

| Property | Default | Used for |
|---|---|---|
| `judge.apiBaseUrl` | `https://okjudge.com` | Debug API base (release is always production) |
| `judge.shareBaseUrl` | API base | `/v/<id>` share links |
| `judge.turnstileSiteKey` | empty | Public Turnstile key; empty disables the bot check (debug only: release packaging fails without it) |
| `judge.googleServerClientId` | Judge's web client id | OAuth client id Google issues ID tokens for (public) |
| `judge.revenuecatApiKey` | empty | Public RevenueCat SDK key for Google Play (`goog_...`); empty keeps purchases off ("Coming soon") |

## Purchases (RevenueCat)

Google Play products: one-time (consumable) `pack_1` and `pack_10`, and the
subscription `monthly` with base plan `p1m`. The RevenueCat current offering
must contain a package for each; the app matches packages by product id.
The SDK is configured only once `/api/v1/me` names the signed-in user, with
that user id as the RevenueCat app user id, and logs out on sign-out. The app
grants nothing itself: after a purchase it re-reads `/me` for about ten
seconds while the server's webhook adds the credits or the plan.

Local dev server: `-Pjudge.apiBaseUrl=http://10.0.2.2:3000` (emulator) or
`http://localhost:3000` with `adb reverse tcp:3000 tcp:3000`. Debug builds allow
cleartext http only to those hosts (`src/debug/res/xml/network_security_config.xml`);
release builds stay HTTPS only.

## Tests

- Display ports are checked against `../shared/fixtures` (exported from the web
  code by `npx tsx mobile/shared/fixtures/export-fixtures.ts`).
- Robolectric runs on JDK 25 with the `--add-opens`/`--add-exports` flags in
  `app/build.gradle.kts`; tests pin `sdk = 36`.
- Screenshots (Roborazzi, written only in record mode):
  `./gradlew recordRoborazziDebug --tests "*ScreenshotsTest*" -Pjudge.shotsDir=<dir>`
- Live check (one real verdict, costs a few cents):
  `./gradlew testDebugUnitTest --tests "*LiveApiCheck*" -Pjudge.liveCheck=true [-Pjudge.liveBaseUrl=...]`

## Strings

`res/values*/strings.xml` and `i18n/Strings.kt` are generated by
`npx tsx mobile/shared/strings/export-strings.ts`; never edit them by hand.
The purchase copy in `res/values*/strings_purchases.xml` (`i18n/PurchaseStrings.kt`)
is hand-written for now and moves to the shared exporter later.
