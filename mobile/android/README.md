# Judge for Android

Kotlin + Jetpack Compose, phase 1 (no sign-in). Package `com.okjudge.judge`
(debug builds add `.debug`).

## Build

Needs the Android SDK (`local.properties` with `sdk.dir`, not committed) and a
JDK. Android Studio's bundled JBR (JDK 25) works:

```sh
# Git Bash; in PowerShell set $env:JAVA_HOME instead
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
./gradlew assembleDebug testDebugUnitTest
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Toolchain: Gradle 9.8.2, AGP 9.4.1 (built-in Kotlin), Kotlin 2.4.21, KSP
2.3.12, compileSdk 37, targetSdk 36, minSdk 26, Java 17 bytecode.

## Configuration (`gradle.properties` or `-P`)

| Property | Default | Used for |
|---|---|---|
| `judge.apiBaseUrl` | `https://okjudge.com` | Debug API base (release is always production) |
| `judge.shareBaseUrl` | API base | `/v/<id>` share links |
| `judge.turnstileSiteKey` | empty | Public Turnstile key; empty disables the bot check (debug only: release packaging fails without it) |

Local dev server: `-Pjudge.apiBaseUrl=http://10.0.2.2:3000` (emulator) or
`http://localhost:3000` with `adb reverse tcp:3000 tcp:3000`. Debug builds allow
cleartext http only to those hosts (`src/debug/res/xml/network_security_config.xml`);
release builds stay HTTPS only.

## Tests

- Display ports are checked against `../shared/fixtures` (exported from the web
  code by `npx tsx mobile/shared/fixtures/export-fixtures.ts`).
- Robolectric runs on JDK 25 with the `--add-opens`/`--add-exports` flags in
  `app/build.gradle.kts`; tests pin `sdk = 36`.
- Screenshots (Roborazzi, written only in record mode):
  `./gradlew recordRoborazziDebug --tests "*ScreenshotsTest*" -Pjudge.shotsDir=<dir>`
- Live check (one real verdict, costs a few cents):
  `./gradlew testDebugUnitTest --tests "*LiveApiCheck*" -Pjudge.liveCheck=true [-Pjudge.liveBaseUrl=...]`

## Strings

`res/values*/strings.xml` and `i18n/Strings.kt` are generated by
`npx tsx mobile/shared/strings/export-strings.ts`; never edit them by hand.
